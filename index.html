Get Started

Strong Cryptography

Argon2id for key derivation and AES-256-GCM for authenticated encryption.

Security-First

Zero-knowledge style vault. Atomic file writes to prevent corruption.

Developer CLI

Built with Typer for a clean, intuitive command-line experience.

Fully Local

Lightweight, no external dependencies, and clipboard integration.

Installation

Quick Install

pip install git+https://github.com/Iced-code/ankylo.git

Build from Source

git clone https://github.com/Iced-code/ankylo.git
        cd ankylo
        pip install .

Usage

ankylo init
        ankylo add -n github
        ankylo get -n github --show
